# Changelog

All notable changes to AEPCodes Themes are documented here.

## 1.0.2 - 2026-08-30

- Improved native comment gutter button contrast across all light and dark themes.
- Added explicit colors for normal, unresolved, and draft comment glyphs.

## 1.0.1 - 2026-08-30

- Added repository, homepage, and issue-tracker links to the extension metadata.
- Linked the user-facing README to the maintainer development guide.

## 0.1.0 - 2026-08-30

- Added light and dark Caltagirone Dusk themes.
- Added light and dark Etna & Travertine themes.
- Added light and dark Conca d'Oro themes.
- Added complete workbench, TextMate, semantic-token, terminal, diagnostic, Git, diff, settings, notebook, and debugger coloring.
- Added deterministic generation and stale-file validation.
- Licensed the extension under GNU AGPL v3.0 only.
- Kept theme-picker labels concise by omitting the extension-name prefix.
- Added an original theme-color palette icon with a transparent background.
- Moved maintainer workflows into `DEVELOPMENT.md` so the README focuses on using the themes.
